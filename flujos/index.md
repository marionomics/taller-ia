# Manos a la obra: ocho flujos de trabajo

Un **flujo de trabajo** es una receta paso a paso para resolver una tarea concreta de tu investigación: qué preparas tú antes, qué *prompt* le das a la IA y cómo revisas lo que te entrega. Aquí hay ocho, en el orden en que esas tareas suelen aparecer en una investigación. Todos empiezan con el Flujo 1; después, cada quien va al que corresponde a la etapa en que está:

| Si estás aquí… | Ve al… |
| --- | --- |
| No tengo tema | [Flujo 2](flujo-2.md) |
| Tengo tema, pero no un plan | [Flujo 3](flujo-3.md) |
| Necesito literatura y marco teórico | [Flujo 4](flujo-4.md) |
| Voy a levantar mis propios datos | [Flujo 5](flujo-5.md) |
| Ya tengo datos para analizar | [Flujo 6](flujo-6.md) |
| Quiero un formulario, tablero o herramienta | [Flujo 7](flujo-7.md) |
| Tengo un borrador y quiero que lo revisen | [Flujo 8](flujo-8.md) |

La investigación sigue un método, paso por paso. A veces tendrás que regresar a corregir algo que ya habías hecho; es normal y no cambia el método. En cada *prompt*, cambia lo que está entre llaves `{ }`.
