# Checklist antes de entregar

- [ ] Cada referencia existe, la abrí y dice lo que digo que dice.
- [ ] Cada número sale de un script que corre de principio a fin.
- [ ] Escribí qué esperaba encontrar antes de correr el análisis.
- [ ] Repliqué a mano al menos una estimación clave.
- [ ] Puedo explicar cada decisión metodológica sin apoyo.
- [ ] Ninguna oración del texto fue redactada por la IA.
- [ ] No subí datos personales ni confidenciales a servicios externos.
- [ ] Incluí la declaración de uso de IA.
- [ ] Si mañana se supiera todo lo que hizo la IA, el valor de mi trabajo no cambiaría.
