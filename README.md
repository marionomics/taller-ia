# IA aplicada a la investigación científica

Guía del curso-taller del Dr. Mario A. García Meza (Marionomics), publicada en https://ia.marionomics.com.

- El contenido está en archivos Markdown; cada archivo es una página del sitio.
- El sitio se genera con [Retype](https://retype.com). Para verlo en tu computadora: `npm install -g retypeapp` y luego `retype start`.
- Cada push a `main` publica el sitio automáticamente (GitHub Actions → rama `retype` → GitHub Pages).
- Los formularios de correo usan el endpoint público `/subscribe` de Notifuse (listas `taller-ia` y `fullstack`). El código está en `_includes/body.html`.
- La página `/unirme/?email=...` suscribe a la lista principal; se usa en el último correo de la secuencia del taller.
